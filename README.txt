SORRY WEBSITE — QUICK START

1. Extract sorry_website.zip.
2. Open the extracted folder.
3. Double-click index.html to open the website in your browser.
4. To edit your apology, open message.html in VS Code.
5. Find the paragraph with class="your-message" and replace the placeholder text with your own message.

PAGES
- index.html: first sorry page and accept-my-sorry button
- memories.html: four cards (one message card + three coming soon)
- message.html: your personal apology letter
- style.css: colors, layout, responsive design and animations
- script.js: small entrance animation helper

TIP
You can change the names, headings, colors and wording directly in the HTML/CSS files.
The Google Fonts import requires an internet connection; the website still works offline with fallback fonts.
